按你当前这版程序，全部引脚连接如下：

1. `OLED 0.96 (软件I2C)`
- `VCC -> 3.3V`
- `GND -> GND`
- `SCL -> PB8`
- `SDA -> PB9`

2. `DHT11 温湿度`
- `VCC -> 3.3V`
- `GND -> GND`
- `DATA -> PA5`
- `DATA` 建议上拉 `4.7k~10k` 到 `3.3V`（若模块板已带上拉可不加）

3. `MQ135 空气质量（当前用 DO 数字口）`
- `VCC -> 5V`（常见模块）
- `GND -> GND`
- `DO -> PC4`

4. `PIR 人体红外`
- `VCC -> 5V`（常见 HC-SR501）
- `GND -> GND`
- `OUT -> PA1`

5. `按键输入`
- 使用板载按键 `PA0`（中断触发）

6. `双舵机（柜门）`
- `Servo1 信号 -> PA2`（TIM2_CH3）
- `Servo2 信号 -> PA3`（TIM2_CH4）
- 两个舵机 `VCC -> 外部5V电源`（不要直接吃板载3.3V）
- 两个舵机 `GND -> 外部电源GND`
- `外部电源GND` 必须与 `开发板GND` 共地

7. `串口1 调试（115200）`
- `PA9 (USART1_TX) -> USB转串口 RX`
- `PA10 (USART1_RX) -> USB转串口 TX`
- `GND 共地`

8. `板载LED`
- `PC5`：人体红外联动灯（低电平点亮）
- `PB2`：运行指示灯（程序中周期翻转）
